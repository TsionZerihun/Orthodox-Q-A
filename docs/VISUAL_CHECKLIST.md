# Visual acceptance checklist

Authority: frontend/public/references and public/references; do not use older rejected native HTML mocks as the final target.

- [ ] Logo: small gold open Bible/cross and consistent Orthodox Q&A wordmark on every page.
- [ ] Ivory light background; quiet manuscript/geometry; subtle gold, no excessive gold blocks.
- [ ] Dark charcoal backgrounds, neutral borders and readable muted text; restrained gold actions.
- [ ] Main-page header ornamental detail; no human/saint figures on account screens.
- [ ] Tiny top-left manuscript card corners; consistent border/radius/spacing; no heavy full-frame decoration.
- [ ] Shared outline icon family, sizes, alignment, stroke widths, text baselines.
- [ ] Serif headings; calm body type; Ethiopic font fallback and line-height.
- [ ] Desktop header/search/ask/bell/theme/account and three-column balance.
- [ ] Topic navigation, selected states, Trending/Latest/Unanswered/Following.
- [ ] All question cards, answer previews, reference styling, photos, Author labels and verified badges.
- [ ] Helpful votes distinct from question upvotes; no self-votes or identity leaks.
- [ ] More answers, all eight accessible, reply expansion, image enlarge/alt text.
- [ ] Post menu, edit/report/share, keyboard operation, validation/loading/empty/error states.
- [ ] Hover about 180ms, press about 120ms; focus ring; reduced motion.
- [ ] Mobile navigation, comfortable targets, no horizontal overflow, matching dark/mobile states.
- [ ] All 11 main design destinations and supporting states implemented before full-project signoff.

Reference availability is complete; feature and visual acceptance is not. Checkboxes represent verification still to perform, not missing reference files.
