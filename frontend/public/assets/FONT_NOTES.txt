Typography notes for Orthodox Q&A homepage fidelity work

- The approved mock’s exact typeface is not identified from evidence in this repository.
- Closest licensed substitutes in use (via next/font / Google Fonts, SIL Open Font License):
  - Playfair Display — high-contrast serif for brand, headings, and question titles
  - Source Sans 3 — lighter readable sans for metadata, excerpts, and UI chrome
- Ethiopic UI text continues to use the bundled Noto Ethiopic (SIL OFL) in ethiopic.woff2.
